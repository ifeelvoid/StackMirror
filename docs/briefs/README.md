# Briefs

Briefs record why material work is being done before implementation starts.

- Drafts live in `_drafts/` without a serial.
- Filing a draft assigns the next serial and creates `NNNN-slug/brief.md`.
- Execution records factual results in the adjacent `ledger.md`.
- Statuses are `pending`, `in-progress`, `deferred`, `done`, or `skipped`.
