# Security policy

## Supported versions

Security fixes are applied to the latest source on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected credential, session, or publishing vulnerability. Email `ifeelvoid@proton.me` with a concise reproduction, affected version or commit, and impact. Do not include live API keys, cookies, or subscriber data.

StackMirror keeps the Substack session in the macOS Keychain and does not bundle credentials.
